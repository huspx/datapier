# Datapier UI 设计说明

[交互设计稿](ui-redesign.html)是唯一 HTML 设计入口，展示 MySQL、Redis、查询、编辑、草稿、详情及 MCP 待办等示例。跨功能的视觉与组件目标统一见 [UI 设计规范](ui-guidelines.md)，本说明维护具体功能的操作语义；产品范围见[README](../README.md)，当前接口及来源边界见 [0.2.0 技术方案](technical-design-0.2.0.md)与 [0.3.0 技术方案](technical-design-0.3.0.md)。历史版本的设计与验收保留在对应方案，示例覆盖不代表全部功能已对齐。

入口通过相对路径加载 `assets/ui-redesign/` 下按职责拆分的样式与经典脚本，保留原有级联和执行顺序。直接打开 HTML 或通过 HTTP 预览时，需保留该资源目录；无构建步骤。

## 设计稿的使用边界

设计稿使用页面内示例数据，不连接数据库、不执行 SQL／Redis 命令、不持久化工作区、不生成导出文件。单元格与类型编辑进入本地示例草稿；提交按钮只演示确认与草稿收尾。新增行和导出入口展示表单，不代表已执行真实操作。生产实现必须使用 Engine／Core 的现有路径。

顶栏的数据库类型、状态选择器和示例说明是预览工具，不进入产品。SQL 的执行动作展示精确请求文本并标记“未发送”；结果样例从预览状态显式打开，不能据此推断查询执行成功。主机、连接名称、库表、key、时间及业务数据均为示例。

浏览器布局和事件不构成 TSP API 承诺。原生界面使用公开元素、稳定 key、受支持的 CSS 和实际数据；生产能力与限制以技术方案、源码和运行证据为准，交互目标与当前实现的差异应明确记录，不能据缺少 HTML 示例改写设计目标。截图仅用于本地视觉核对，不纳入 Git，也不在设计文档中引用；操作演示保留 README 的 demo GIF。

0.1.1 的 HTML 交互稿展示 Archery 服务认证、实例和 DB 批量选择、只读结果、平台历史、MySQL 上线 SQL 检查及认证恢复。HTML 顶部通过 Direct／Archery 来源和状态选择器切换示例；这些预览控件不进入产品。macOS arm64 是本版原生运行验收平台，其他目标保留实现，在 PR 阶段验证编译；实际证据和环境见[0.1.1 运行记录](technical-design-0.1.1.md#12-实现与验证记录)，不以示例替代原生验收。

原生品牌入口、导航来源角标、形状连接状态、CLI 连续记录、直连比例高度调整及 Archery 全高布局已接入，并在实际 Tern 验证。直连高度采用 Tern 公开 split 比例契约，窗口缩放时保持比例；不再采用固定像素步长及像素高度恢复设计。HTML 示例使用相同比例规则，原生验收仍独立进行。

## 布局与视觉

左侧为共享连接导航，依次放置品牌、新建连接、连接列表和当前连接资源树，底部固定为 Datapier 设置、快捷键帮助和退出。右侧依次为连接／数据库上下文、标签、主内容和底部状态栏。Redis CLI 在主内容下方独立展开，不替换 key 详情。

| 元素 | HTML 基准 |
|---|---|
| 正文／数据 | Geist sans／宿主等宽字体，浏览器使用对应回退；正文 13px／数据 11px |
| 表头／类型副行 | 高 42px、文字 12px／9px |
| 表格数据行／Redis key 行 | 35px／36px |
| 展开导航／窄轨 | 224px／58px |
| 品牌标记／整行热区 | 36px／62px 高 |
| 上下文栏／标签／分区导航 | 最小 54px／39px／28px |
| 底部状态栏 | 最小 29px |
| Redis key 浏览区 | 宽屏 284px，1000px 以下 240px，760px 以下 210px |
| Redis CLI | 直连默认占上下 pane 的 35%，可调 15%–85%；数据区至少保留 8 个宿主文本行，CLI 按宽窄提高最小空间以容纳头部、记录和输入；Archery 占满主工作区 |
| 原生按钮／图标 | 高 28px／14px；quiet、default、primary、danger 保持各自语义 |
| 对话框 | 常规表单参考宽度约 720px；长正文与并排比较可使用宽版，受视口及宿主空间约束；默认边缘至少 20px，正文滚动、头尾可达 |

细分隔线表达区域层级；选中项使用选中底色，活动标签使用下划线，草稿使用警示色和单元格边缘标记。数字右对齐，所有 grid 的序号列表头 `#` 水平及垂直居中，Redis value 区 grid 标题行垂直居中；NULL 使用独立弱化样式。输入、菜单和图标操作有焦点态、tooltip 及可访问名称。

HTML 的明暗演示匹配宿主当前主题色值；原生沿用宿主语义主题 token 及 `--sans`／`--mono`，字体在浏览器中使用 Geist 和宿主 mono 对应的回退。overlay 与按钮皮肤以当前原生 SDK 实现为准，设计稿对齐其圆角、遮罩、标题字重和控件，不改宿主默认皮肤。视口进入 760px 及以下时以响应式状态自动收起到 58px 窄轨；手动展开时导航覆盖剩余主区，窄轨仍占位。返回宽屏恢复独立的宽屏用户偏好，窄屏自动收起和手动展开均不覆盖该偏好；再次进入窄屏重新自动收起。品牌入口始终可达，窄轨仍可选择连接。次要上下文信息按空间隐藏，工具栏允许换行，数据区域内部滚动。

窄屏连接表单将并排字段改为单列，类型卡片中的图标与文字纵向排列，footer 操作可换行；正文独立滚动，标题和主操作保留在弹窗内。长服务器名称、地址和账号允许断行，服务器行的编辑与删除按钮保留空间。

连接、数据库树和 Redis 列表／树采用左对齐平面行，不显示按钮边框或阴影；悬停与选中通过底色区分。列表／树切换使用两个带选中态的 quiet 图标按钮，分别使用 SDK 可用的 list／tree 图标，并提供 tooltip 和可访问名称。品牌、数据库类型标签左对齐；标签按设计稿使用资源或 SQL 图标，Redis 标签使用 layers，新增入口固定在标签栏最右侧，整个标签及关闭区共用悬停底色；历史入口位于侧栏。grid 使用直角、细分隔线、明确的选中、编辑、草稿和 NULL 样式；普通数据字段包括 status 样例一律显示通用文本，不按值着色。应用菜单动作均带图标；宿主自动附加的原生 `Copy` 只复制右击节点展示文字，不能读取应用选区或完整大值。Redis 详情标题和条目工具栏删除按钮的背景、边框及 hover 与其他 quiet 按钮相同，仅 trash 图标使用危险色；删除菜单项和确认按钮保留 danger 语义。分页沿用原生“本页 N 行 · 共 N 行”“第 N 页”，选择提示只显示当前平台的修饰键，单元格详情入口位于底部右侧。连接表单的测试和保存保留清晰文字操作，TLS 与证书入口及其字段左对齐。

SDK 0.2.0 的 overlay 正文使用稳定 key，避免 slot 排序改变焦点 ID。Tern 0.9.9 中，下拉展开期间仅临时放开 overlay 滚动区裁切，选中或 Escape 关闭后恢复宿主滚动；不叠加旧弹窗的滚动容器。

### 品牌与图标

品牌使用本地 [Datapier SVG](assets/datapier.svg)。标记、名称和整行空白共用一个收展按钮：展开左对齐，收起时标记在窄轨中居中。收展状态归工作区所有，跨连接、类型和标签保持，首次默认展开，重开恢复。

MySQL／Redis 使用固定版本的本地 Devicon SVG，来源、许可证和适配见[资源清单](assets/providers/devicon.json)。HTML 品牌和数据库图标均通过 `img` 直接引用本地 SVG；MySQL 使用资源内置颜色，Redis 保留彩色叠层；库对象仍使用通用 `database` 图标。原生通过 `Session::blob` 与公开 `image` 加载。

Archery [主图](assets/archery.svg)以“数据库＋审核入口”表达 SQL 审核和受控访问，入口内的 A 保留名称识别。右上角[三角来源角标](assets/archery-badge.svg)只提炼同一 A 形入口，不缩放整幅主图，不使用靶心或箭头。主图用于 Archery 类型和服务器入口；角标叠加在 MySQL／Redis 类型主图右上，避免遮挡主要轮廓。来源角标不表示连接成功、审核通过或写入权限；资源用途和许可见[资源说明](assets/archery-assets-LICENSE.txt)。

MySQL 和 Redis 的两个 SVG 内嵌完整 Devicon MIT 版权及许可声明；声明随 `include_bytes!` 进入原生二进制，独立许可证仍随源码保留，资源清单记录适配后的摘要。

通用动作复用 Tern SDK 图标；实例、数据库与资源刷新统一使用 `repeat` 图标和 28px quiet 图标按钮，颜色跟随主题，保留 tooltip、可访问名称与禁用态。应用侧栏显示 Datapier SVG；启动 plugin 与命令面板使用内置 `database`，运行程序 tab 图标由宿主决定。图标库仅分发实际使用的文件及许可证。

## 连接、资源与标签

- 连接列表以 MySQL／Redis 类型图标为主体；Archery 来源角标固定右上，并直接引用最新三角来源资源，Direct 不显示来源角标。连接状态统一放右下，沿用 0.1.0 的 9px 外径、2px 分隔描边和向外偏移 1px；展开和窄轨使用相同规则：未连接为空心点、已连接为实心点、连接中为缺口圆环、失败带感叹号，不只依赖颜色。名称旁不再显示文字连接状态，长名称单行省略；直连副行显示 host:port，Archery 副行显示服务器等实际信息。tooltip 和可访问名称保留完整名称、来源、地址、状态及失败原因。状态按连接聚合，不能把非当前连接视为未连接。
- 连接设置、复制名称和删除连接放在对应连接右键菜单，连接设置表单不另放删除按钮。MySQL 直连另提供“新建数据库…”与“关闭连接”：仅在连接已建立且可写时允许建库，可在未选择数据库时打开；短表单从当前服务器读取字符集和排序规则候选，选择字符集后筛选对应排序规则，加载失败或响应不完整显示错误，不使用内置列表。随输入实时生成冻结 DDL 预览，不另设预览步骤，只有对应当前输入的计划就绪后才能执行；取消直接关闭，不二次确认。Redis 和 Archery 隐藏建库入口。关闭连接先整体检查所属前后台标签的草稿与任务，等待相关会话关闭后移除全部所属 tab、清空数据库树并拒收迟到结果，保留配置和其他连接；再次点击连接行建立新连接和 tab。删除 MySQL 或 Redis 连接冻结目标并二次确认，先关闭全部所属 tab 和已建立会话，再删除配置；失败保留配置，其他窗口占用明确报错。Archery 的连接设置打开服务器连接管理，批量删除以预览并保存为确认。连接失败显示原因、重试及设置入口；MySQL 3159 另显示“启用 TLS”，只修改表单，保存后重连；测试失败保留表单输入。
- 直连新建表单从默认值开始：MySQL、127.0.0.1、3306，名称、用户名、密码、默认库、数据库勾选和错误为空，TLS 关闭且证书路径为空，Redis DB 为 0、访问模式为只读。点击连接设置时先对当前工作区该连接的全部标签整体预检；任何草稿或运行任务阻止整个关闭动作，全部可关闭后才关闭并打开表单，其他连接标签保留。测试失败保留输入。MySQL 表单可加载数据库、按名称搜索、多选、选择或取消匹配项；搜索不清空勾选。保存配置后重连，状态和仍存在的所属标签按新模式刷新，不自动重建已关闭的标签；失败显示原因。HTML 只展示示例状态，不建立连接或保存配置。
- 设置名称使用“时区”“连接超时”“执行超时”等通用词汇，按数据库能力展示；当前 MySQL 时区默认 `+00:00`，留空使用服务器默认，可填写 `SYSTEM`、合法偏移或时区名称，名称可用性由服务器验证。新建连接和连接设置共用默认收起的“超时设置”，位于“TLS 与证书”上方；两个超时字段以秒为单位，范围 `1–86400`，留空继承全局值，重新编辑不丢失值，校验失败自动展开并定位。传输和结果固定 `utf8mb4`，不提供 GBK／Big5 等连接编码选项；这不限制新建数据库或表字段自身的存储字符集。关闭 SQLx 通过 `SET sql_mode` 追加模式的选项，但官方驱动握手仍固定启用 `IGNORE_SPACE`；DDL 以实际会话模式为基线，不恢复旧创建模式或字符集，预览说明上下文迁移。
- 新建连接 dialog 的内容最上方始终以 MySQL、Redis、Archery 三个同级卡片呈现类型，包括 Archery 连接预览步骤；预览中卡片保留选中态并禁用切换，返回配置后可切换。Archery 使用原创自绘图标，前两者为直连，底层 provider 仍只区分 mysql／redis；卡片支持键盘单选。直连切换类型展示对应字段及默认端口，不丢失无关表单输入；连接右键共用基础操作并按能力显示。
- 直连新建表单最初没有已加载候选或勾选；首次加载后默认勾选全部可访问库，用户取消选择才形成显式显示范围。未设置范围表示全部，显式空范围表示全部隐藏；重新加载不能覆盖用户的勾选。
- MySQL 树按 database → 表／视图 → 对象展开，数据库和对象左对齐，表／视图组可独立收展，刷新图标位于筛选框右侧。未设置显示范围表示全部可访问库，显式空列表表示全部不显示；显示范围不等于权限。隐藏库不关闭其已有标签或丢弃草稿，迟到响应不能重新插入隐藏库。
- 树外对象筛选与数据行筛选相互独立。筛选保留数据库节点及无匹配空态；打开对象携带明确的连接和 database target。
- 数据库右键提供展开／折叠、刷新、复制名称和删除；表右键增加结构、DDL 和删除。删除仅限可写 MySQL，冻结连接和限定资源，确认前复核归属及草稿／任务。保存配置与现有会话不一致时要求先重连。DROP 使用专用会话，保护用户原 SQL 事务；结束后等待会话关闭并刷新受影响资源，结果未知不重放。关闭弹窗后仍可在状态栏停止等待。HTML 仅移除页面内示例资源。
- Redis 顶部下拉使用实际探测的逻辑 DB 数量，连接表单可手动覆盖数量；探测中、未知或失败保持可读反馈，不能默认声称只有 16 个 DB。范围外的当前 DB 保留为额外选项，Archery 使用已保存的可访问范围。候选项不修改服务端配置；不支持的 DB 返回原始错误并保留之前可用上下文。切换前处理草稿、运行任务与输入，连接成功后替换会话，旧扫描与响应不得污染新 DB。HTML 数量与状态均为本地示例，不发起探测；为限制示例 DOM 数量，最多列出前 1024 项及当前 DB，并明确提示展示范围。
- 标签标题和关闭按钮并列，关闭图标紧贴名称；macOS 在名称左侧，Windows／Linux 在右侧，标题与关闭区共享悬停底色。资源标签与 SQL 标签显示对应图标，新增入口固定在标签栏右侧。右键冻结目标标签 ID，按其位置关闭左侧、右侧或所有标签；对目标集合整体预检草稿和任务，任何阻塞均不关闭任何标签。关闭全部后显示垂直居中的零标签空态：宽屏提供新建查询，窄轨状态额外提供选择连接；展开侧栏时也可直接选择连接。新连接不能覆盖旧资源归属。
- 原生切换或新建标签、资源标题到达及导航／视口宽度改变后，使用宿主 nearest reveal 将活动标签滚入可视区域；普通后台刷新不打断手动横向浏览标签。
- 侧栏底部依次为设置、快捷键帮助和退出：展开时图标与文字左对齐，窄轨中图标居中。无连接空态和已有连接时帮助入口均打开相同 overlay；空态也渲染 overlay 层，支持关闭及键盘操作。退出与 Ctrl+Q 共用保存工作区后返回 shell 的路径，保存失败保留工作台，未提交修改保留为草稿。

## Archery 来源

Archery 使用同一连接导航、数据库上下文、标签、结果 grid 和状态入口；类型主图、右上来源角标和右下连接状态分别表达不同信息，副行显示服务器等实际信息。MySQL 通过左侧 DB 树导航同一实例的数据库，右侧不显示 DB 切换下拉，保留数据库／关系浏览和结构、DDL。Redis 保留所选 DB 下拉，以占满右侧剩余高度的 CLI 作为主界面，仅提供平台文本命令结果，不展示原始 key 树、TTL 或编辑入口。来源决定可用操作，不能因存在普通 grid 而开放写入、导入、事务或工单执行。

### 服务登录与服务器连接管理

- Archery 新建表单提供服务器下拉，以名称和用户名区分账号，旁边使用新增和编辑服务器图标，提供 tooltip 和可访问名称；完成后回到原表单，保留实例及 DB 输入。全局设置的服务器列表显示名称、地址、用户名和关联连接数量，标题右上角使用新增服务器图标，行内编辑使用 pencil、删除使用 danger 色 trash，图标均有 tooltip 和可访问名称；全局和连接上下文共用同一服务器表单。服务器保存 primary 按钮居右，删除二次确认的 danger 主按钮居右。
- 服务器选择器与右侧新增／编辑操作底部对齐；配置和预览步骤常驻。实例使用独立分组，连接名称和数据库列表缩进到所属实例内；默认 DB 操作与对应数据库同排，长名称断行时不挤出操作按钮。
- 服务器保存后地址和用户名只读，变更须另建服务器；规范化地址相同但账号不同可分别保存，同地址同账号不能重复。名称、密码、CA 证书及 TOTP 配置可编辑；名称变更同步服务器相关文案，保留用户自定义连接名。运行任务期间密码、CA 和 TOTP 配置不能保存，名称仍可即时修改。
- CA 与 TOTP 设置摘要常驻，详情默认收起。CA 可选，默认使用信任链；HTTP 时入口可见但禁用并说明仅 HTTPS 使用。TOTP 默认手动，也可配置本机自动生成的 `otpauth://totp/...`；可替换或清除配置，已保存种子不回显，不自动启用平台双因素认证或绑定二维码。密码和种子分别按服务器保存到系统凭据库，凭据库不可用时仅保留在 Engine 会话；OTP、Cookie 和 CSRF 仅存内存。验证码支持整段粘贴；系统直接填充仅作为宿主能力待验证，不提供密码管理器专属入口或新增系统桥接。
- 认证弹窗独立于服务器表单和实例选择：缺密码先输入密码，平台要求时进入验证码；已保存密码先自动认证，只有需要 OTP 时才显示输入。配置自动 TOTP 可自动恢复，失败可手动输入，不循环重试；验证后清空 OTP。认证期间可停止等待，错误保持可见，不提前显示已登录。
- 同一 Engine、同一服务器配置的所有实例和窗口共享登录会话，不同账号或数据目录隔离；并发过期仅进行一轮认证、显示一个弹窗，其他窗口等待。弹窗所属窗口退出时释放认证所有权，由等待窗口接手；取消不注销其他窗口已就绪会话。首次连接需要认证时，成功后自动续接原连接请求一次；认证变化保留查询、目标和缓存，失败 SQL／Redis 命令不自动重放。
- 右键 Archery 连接的“连接设置”打开“服务器连接管理”，固定当前服务器和账号，显示该账号全部 MySQL／Redis 实例及 DB，回填所有已保存连接，自动展开并定位右击实例。实例区参考 MySQL 的数据库范围选择，标题为“显示在资源树中的实例与数据库”，带真实刷新图标及 tooltip，不提供筛选、搜索或选择匹配项。DB 按实例逐级展开加载；每个勾选实例形成一个连接，可编辑名称（新增默认实例名）、DB 范围和默认 DB，范围至少一个 DB，默认 DB 必须在范围内。已有连接的服务器、账号、实例、类型及 UUID 固定，新实例预生成固定 UUID。
- 勾选可新增或修改多个连接；取消已有实例表示待删除其本地连接，勾回恢复原值，取消尚未保存的新实例只移除本次新增。刷新后缺失或权限变化的已保存实例保留节点和选择并显示异常，不自动取消或删除。刷新使用共享 ready 会话，缺凭据或过期时自动读取密码并按需弹出独立密码或验证码认证；认证成功自动继续本次元数据刷新，失败或取消保留选择及输入并显示状态，无常驻登录／验证按钮，也不重放失败 SQL／Redis 命令。
- 创建和管理均分两步：配置步骤的 dialog footer 主按钮为“预览连接”；预览步骤正文分新增、修改、删除，数量为零的组不渲染，非零组列出数量、前后值和删除风险，删除项明确名称、实例、DB 及仅删除本地配置、不删除远端实例、DB 或数据。footer 使用“返回修改”和 primary“保存全部连接”，返回完整保留输入和选择，取消 dialog 不落地；保存该预览即确认删除，不再叠加第三个确认框。无变更不提交，允许取消全部已有实例并保存删除计划，服务器仍保留。
- 预览保留完整基线和差异；保存通过 `archery.profile.apply_batch` 重新检查服务器修订、整组连接基线、身份与受影响连接占用，冲突、草稿、运行任务或其他窗口占用均阻止整批并保留预览，不产生部分变更；未改变的连接不因同服务器而强制关闭。仅新增连接及 DB 配置变更需要校验可见实例与 DB；仅修改本地名称或删除本地连接不强制远端发现成功。历史和结果保留，删除连接不删除共享服务器凭据。服务器凭据与连接分阶段保存，不能声称跨凭据库及 SQLite 原子；响应未知先核对固定 ID 和期望配置，不盲目重试。
- 配置写入期间锁定输入、凭据保存／清除开关和关闭动作，失败后恢复编辑。Escape 与关闭按钮复用清理：服务器子表单返回原管理界面；认证弹窗取消当前等待，迟到响应不得重新打开弹窗。
- 删除服务器前列出关联连接并二次确认“删除服务器及 N 个连接”；有运行任务、草稿或其他相关占用时阻止删除。删除本地配置，不删除远端数据；保留本地历史及执行时归属。
- HTML 的登录、验证、加载和保存仅推进页面内示例状态，外层始终标明示例数据及未发送；不请求 Archery、不生成真实验证码或保存种子及凭据。

### 查询、结果与停止等待

MySQL 只读查询保留全文、选区、当前语句、执行计划和格式化入口。SQL 检查为独立操作，允许输入待上线 SQL，但不进入查询执行路径。Redis 使用独立命令输入与平台文本结果；只读拒绝、错误和空值保持各自语义，不将 SCAN 结果解释为完整 key 浏览。

Archery 来源的 Redis 使用全高 CLI：顶部显示 CLI、实例／DB、命令历史、状态与耗时，中间连续展示执行记录，底部固定命令输入和执行图标，Enter 执行。记录保留每次执行时的命令、实例／DB、状态及返回文本，按执行顺序追加；再次执行、修改输入或切换 DB 时保留已有记录。点击记录内容定位对应结果并恢复分页，不使用编号切换按钮；记录保留辅助技术可访问名称和点击动作。面板占满上下文与标签栏下的剩余高度，短视口下输入与操作可达。记录与滚动规则见 [CLI 公共规则](#redis-类型编辑与-cli)，平台文本与覆盖范围说明保持可见；复制包含全部执行记录、失败原因和各自全部缓存结果，后台读取完整大字段，不受当前页或预览截断影响；导出最近一次或已定位的缓存结果，停止操作明确表示“停止等待”。
CLI 头部区分当前输入目标与定位结果的命令、实例、DB 和耗时；切换 DB 不改变旧记录归属。直连 CLI 的当前输入目标使用命令连接的实际 DB，连接失效时显示未知。成功执行 SELECT 后只改变后续命令的 DB，不改变 key 浏览连接；批次记录保留开始时的 DB，每项结果及复制日志标注该命令执行时的 DB，失败也显示最后确认的命令 DB。AUTH 在创建任务前拒绝，认证命令及解析失败的输入不写入工作区。

右侧工作区的历史、查询文件、复制、导出、刷新与停止复用直连的图标、28px quiet 按钮、tooltip 和可访问名称；按任务、结果及能力控制禁用态。执行与 MySQL 上线 SQL 检查分组，检查采用“文档＋放大镜”图形，tooltip 为“检查上线 SQL（不执行）”，不以勾选框或通过标记表达检查动作。Archery MySQL 的只读身份在实例／DB 上下文标记，执行工具栏与结果底部不重复显示“SQL 结果只读”。配置表单中的默认目标、移除实例等语义操作保留文字，不把预览状态选择器混入产品操作区。

查询工具栏在执行操作旁提供“最多返回”下拉，默认 100 行，可选 100／500／1000 行；修改仅用于下次显式执行，不重查或改写现有缓存，不修改 SQL 自身的 LIMIT。运行中禁用该设置；平台权限、配置及 SQL 自身的限制仍可进一步缩小实际返回范围。

结果头部的“结果说明”使用与刷新、复制、导出相同的 28px quiet info 图标按钮，保留 tooltip 和可访问名称。点击在按钮附近显示非模态 popup，逐项列出执行时的来源、实例、数据库、请求上限、已返回行数、原查询总行数、原始类型、原始字节、覆盖范围、保真度和脱敏状态，已知类型损失单独列出；未知信息统一显示“未提供”。浮层自适应视口边界，长内容在浮层内滚动，编辑区与 grid 尺寸保持不变。再次点击、关闭图标、点击外部或 Escape 均可关闭；Escape 和关闭图标将焦点返回说明按钮。切换标签、DB、实例或结果时关闭浮层，新上下文重新读取对应结果说明。达到请求上限时，在底部返回行数旁显示“已达上限”，tooltip 提示可调大后重新执行，但不保证平台返回更多。

结果底部显示“本页 N 行 · 已返回 M 行”，M 只代表本次返回并保留的范围；页大小候选沿用共享分页器，与 MySQL 数据 grid 使用一致的左右箭头和“第 X / Y 页”。翻页只读取仍保留的数据，不执行 SQL；修改每页数量及重新执行回第一页，空结果为第 1 / 1 页并禁用左右箭头。请求上限、执行时上限、返回范围与页码随所属标签保留。复制和 CSV／JSON 导出遵循实际可用范围及来源说明，不承诺平台未返回或已经释放的数据，也不将 Redis 文本结果编码成原始 key 备份。

切换标签或关闭活动标签后激活相邻标签时，统一恢复该标签的 DB、查询文本、缓存、执行时上限及页码；结果说明中的 DB 必须与所恢复缓存的所属标签一致，不能沿用刚关闭标签的 DB。关闭最后一个标签后保留连接的当前 DB，并进入无标签空态。

任务认证失效时提供重新登录；成功登录后保留文本、目标和 `session_id`，等待用户显式重执行，不自动重放。权限拒绝展示原错误，不误导用户重新登录。停止等待后终止本地轮询并标明远端状态未知，不显示远端已取消或回滚；切换标签、实例或 DB 后，旧响应不能覆盖新上下文。

### 平台历史与 SQL 检查

历史默认随当前连接来源：直连显示当前工作区本地历史，Archery 显示当前服务器、当前账号可见的平台历史，不提供本地／平台手动切换。Archery 本地任务记录仍用于任务状态、缓存和恢复；平台加载失败显示实际错误，不冒充空表或本地历史。打开历史只带入文本，不执行、不切换当前实例或 DB，即使历史行记录了不同目标；当前标签有待提交草稿或运行中任务时拒绝打开，保留原标签和输入。加载、空结果、权限错误和重新认证保持可见。

两种来源的历史与结果使用共享分页布局，候选集及能力过滤遵循 [UI 设计规范的分页规则](ui-guidelines.md#44-详情与结构化数据)，保留合法的当前自定义值；上一页和下一页使用 28px quiet 左右箭头，提供 tooltip、可访问名称及首尾／加载禁用态。只有已知总数才显示“第 X / Y 页”和总条数；未知总数显示“第 X 页”。历史页大小有独立的可访问名称，翻页沿用已提交搜索条件，改变页大小回第一页。

MySQL 上线 SQL 检查明确标注仅检查，不提供提交、审批或执行工单。通过、警告、错误、未完成分别展示；明细使用现有结果分页及大值读取，不将远端 `status=null` 的正常检查响应误判为失败。检查通过不代表工单获准，也不代表 SQL 已执行。

## MySQL 数据与草稿

表标签内分数据、结构和 DDL；可靠完整键和有效基线的基表提供写入入口。视图按 [0.3.0 能力证明](technical-design-0.3.0.md#5-可更新视图)分别开放插入、更新和删除，展示不支持原因；任意 SQL 结果和无法证明映射的视图只读。结构和 DDL 使用对应表样例，真实字段、索引、约束与 DDL 必须来自 catalog。
基表数据工具区从左到右为当前页搜索、过滤与排序（funnel）、列设置（columns）、新增行（plus）、导出（download）、导入（向上箭头）、刷新（repeat）。原生导入使用 SDK 已公开的 `arrow-up`，Tern 0.9.9 不提供 `upload` 图标。排序位于同一个“过滤与排序”具名面板，支持字段与方向，不另设空操作；列设置承载列显示、宽度和冻结。MySQL 和 Redis 的导入与导出分别打开对应单一用途表单，工具按钮使用 quiet 样式。新增仅在可靠键、有效编辑基线及读写模式同时满足时可用，导入要求读写模式；只读不禁用导出、列设置或可用的浏览操作。资源不满足操作前提或任务冲突时按实际状态禁用并说明原因。SQL 只读结果区依次提供结果集切换、筛选本页、列设置、导出和收起。各区均无笼统“更多”入口。

0.2.0 的表浏览与安全只读 SQL 使用实时分页，默认每页 100 行；翻页重新读取，不承诺前后页属于同一快照。初始不自动 COUNT，也不把当前页数量冒充总数；通过“统计总数”显式读取总数，结果显示实际已知状态。不能安全重放的语句只执行一次，通过保留的数据继续读取或回看；达到内存上限时明确提示并禁用继续加载，结果过期或释放后不能自动重放。HTML 提供对应实时、单次、内存上限与过期示例，分页和统计仅操作示例数据。

首屏按新结果的类型选择对应页大小：基表浏览、SQL 结果、Redis 值与 Archery 结果分别使用各自设置；结果切换前仍显示旧页时，也不能沿用旧结果类型选择新页大小。首次读取、后续翻页和每页数量显示必须一致。

导出范围随实际结果来源和模式说明：安全只读源可显式重新查询并流式导出，导出内容可能不同于此前显示的页面；其他结果仅导出仍保留的数据，不能一律称作“完整结果”。Archery 继续仅导出本次返回缓存，并说明平台限制与不完整范围。HTML 只预览导出请求，不生成文件。

结构表按真实字段顺序展示名称、类型、NULL、约束和注释；生成列、自增及默认值保留在约束区域，索引和完整约束继续显示在字段之后。原生注释来自 `information_schema.COLUMNS.COLUMN_COMMENT`，保留中文、多行、长文本和空字符串；未知注释留空，不从字段名生成说明。HTML 使用明确的示例注释，长内容换行。

0.3.0 结构设计以对象为单位维护字段、索引、约束与表选项，展示元数据完整性及版本能力；视图与触发器保留独立正文和对象属性。用户操作先形成结构草稿，再生成冻结计划、读取完整预览并二次确认执行；计划存在时锁定表单，修改前先丢弃计划。DDL 可能隐式提交，执行后展示逐步结果并读回实际结构；结果未知时先核对数据库，不能直接重试。恢复草稿需重新读取当前结构并校验基线，不能恢复旧执行凭据。

结构字段 grid 将“类型”和“长度”分为独立两列：类型格使用下拉选择，展示类型名及 UNSIGNED 等既有后缀，长度格维护参数。CHAR／VARCHAR 的长度以字符计，BINARY／VARBINARY 以字节计，BIT 以位计；DECIMAL／NUMERIC 在同一个长度格填写 `18,4`，依次表示精度与小数位。已有表读回真实参数，新建表使用相同控件；修改参数仍写入完整 MySQL 类型定义。DECIMAL 精度为 1–65，小数位为 0–30 且不超过精度；非法输入就地保留并阻止生成计划。整数类型不提供已废弃的显示宽度。参数修改进入原有类型草稿、冻结 DDL 和结构读回流程。

“允许 NULL”使用 checkbox；主键字段禁用该控件，取消勾选时同步移除冲突的 NULL 默认值。默认值类型与值保持在同一行。约束列只展示主键／外键 icon，快捷主键与上移、下移、删除集中在操作列；扩展属性通过点击行热区切换。

DATETIME、TIMESTAMP 和 TIME 的长度表示小数秒精度，范围为 `0–6`，默认 `0`；例如 `DATETIME(3)` 保留毫秒，`DATETIME(6)` 保留微秒。长度格显示当前真实精度，非法输入保留并阻止生成计划；零精度写入不带参数的类型名，与 MySQL 结构读回保持一致。

编辑结构的三级 tab 为“字段、索引、外键、CHECK、表选项、预览 DDL”。生成计划成功后自动进入“预览 DDL”，集中显示真实冻结 SQL、分页及计划摘要；其他分区保留定义且在计划存在时只读。只切 tab 不丢弃输入或重新发送 DDL，尚无计划时明确指引生成计划；提交仍要求完整读取计划并最终确认。

字段 grid 的主键与外键使用带 tooltip 和可访问名称的 icon；快速指定主键直接修改同一份索引草稿，支持有序复合主键，设为主键时同步设为非 NULL 并移除冲突的 NULL 默认值，取消主键不擅自恢复 NULL。索引列和外键的本表列、引用表、引用列在 grid 内直接选择；复合列顺序与映射逐项保留。引用候选来自真实表列元数据，新建外键默认使用当前数据库，切换引用表后重新选择对应列；读取失败或原值不可见时保留草稿并说明原因。字段、索引与外键的上移、下移、删除归到行末操作列，下方扩展属性不再重复这些动作。

结构三级分区的新增按钮使用带 tooltip 和可访问名称的 `plus` icon，字段、索引与外键的新增操作栏与上方 grid 统一间隔 `8px`。字段及结构对象的 grid 行以非控件区域作为选择热区，点击后切换当前选中项和下方扩展属性；输入框、选择框与行内按钮按各自语义响应，不能由行选择吞掉、重复执行或清空未保存输入。结构字段复用 UTF-16 编辑器处理宿主未执行 native editing 时的按键、粘贴和撤销。只读及计划冻结时仍可切换查看扩展属性。

批量替换工作台区分准备、冻结预览、逐项排除、提交和结果状态。MySQL 明确选中行、当前页或当前筛选范围及所选文本列；Redis 明确已选 key 和 String／Hash／List／Set／ZSet 内容或身份角色。准备后保留匹配前后值、原行或成员身份和期限信息；条件变化、数据源变化或计划失效时，须明确丢弃并重新准备。首错停止的结果分别列出已生效、冲突、失败及未执行项，不能将部分生效显示为整体成功。HTML 结构预览由当前示例草稿生成，替换预览以固定样例演示计划切换和逐项排除，均不执行数据库操作。

MySQL 数据表头使用现有实现的类型简名，不附示例长度或精度。MySQL 表和 SQL 结果 grid 的自动列宽根据当前页实际显示内容及可用宽度分配，每列最小 64px、最大 480px；超过各列总上限的空间可留白，窄屏在数据区内横向滚动。Redis 和 CLI 列宽沿用各自既有策略。手动设置的宽度持续生效；原位编辑期间冻结列宽，不因内容变化重排，退出编辑后恢复正常自适应。避免每次 render 重复扫描数据。

MySQL 与 Redis 复合类型 grid 的数据单元格普通点击选中单格，Shift 点击选择矩形区域，不触发行选择。行号负责行或条目选择：普通点击单选、Shift 连选、macOS Command 或 Windows／Linux Ctrl 增选与取消；底部只提示当前 UI 平台的修饰键。右击已选行保留多选，右击未选行先单选目标。

双击、Enter 或 F2 打开唯一的原位编辑器；Enter 或失焦保留草稿，Esc 取消本次输入，Tab／Shift+Tab 保留草稿并移动到相邻编辑格。修改主键值后仍按原行身份维护选择和编辑目标。长值、JSON、NULL 和结构化输入使用独立编辑控件，不能把多行内容撑进固定行高。

0.3.0 高级值编辑从单元格详情或 Redis 值工具栏进入；Redis 复合类型使用选中条目的 value 或 member。弹窗提供文本、Hex、JSON、XML 和图片模式；文本及 Hex 修改先“应用修改”，再“加入草稿”，后者不直接写入数据库。JSON／XML 提供校验和格式化；图片模式先说明生成的图片会被宿主缓存，再由用户显式生成预览。文件区提供路径、覆盖选择、导入／导出及外部编辑入口；编辑文件读取后仍需加入草稿。浏览器设计稿的示例仅演示控件，不读取数据库或启动外部程序。

“应用修改”仅更新值会话，尚未加入草稿时关闭仍须继续编辑或明确丢弃；成功加入草稿后显示实际暂存状态。普通字段 drawer 切到设置、历史或诊断时，同样保护未应用输入。

草稿按连接、资源及原行身份归属；变更预览先完整列出实际参数化 SQL 或 Redis 命令，再按语句分组展示紧凑的有序参数表，逐项显示序号、类型、字节数与可换行的值，保留完整／截断及动态值语义。明确事务、校验、TTL、脚本和错误边界；缺少完整数据时明确不可预览，不伪造值或声称已发送。HTML 使用参数化 SQL 和对应参数的独立示例，明确不连接或执行；真实提交由 Engine 校验类型、权限、原值、可靠键和冲突，失败不得冒充成功。

复制选中行及 INSERT 直接写剪贴板，使用当前草稿和全部实际列，包括隐藏列。INSERT 仅用于来源和 schema 明确的 MySQL 基表，生成列始终省略；第二种操作额外省略同时具有自增和主键标志的列。标志来自真实元数据，不能按列名推断。NULL、精确数值、文本、二进制、JSON 与大值按类型无损编码；缺少完整值或无法安全编码时整体失败，不复制截断值或部分 SQL。

选中单元格或矩形选区可使用应用右键菜单“复制选中单元格”，也可点击 grid 底部 copy 图标；grid 不绑定 Ctrl+C 或 Command+C。文本编辑器拥有焦点时由编辑器处理复制。复制按既有 TSV、NULL 和二进制保真规则在后台完整读取大值后写入剪贴板，读取失败时不复制截断值或部分选区。菜单保留 Tern 自动附加的原生 `Copy`：它只复制右击节点展示文字，不能读取应用选区或完整大值。

行号和单元格右键的行复制、两种 INSERT、删除均使用同一精确行集；全部列隐藏时，行号菜单仍可操作。菜单不提供查看或编辑单元格，单元格详情由底部入口打开。删除 N 行先冻结目标并确认，确认前不生成删除草稿，确认后复核原始可靠键与完整上下文；已有编辑、重复删除或过期目标拒绝整批操作。已标记删除的行不能继续原位编辑、从详情写入或接受粘贴，提交前还会拒绝重复行身份。

全局表单规则：语义必填字段显示与标签同一行的红色 `*`，条件必填随状态变化；Field 的 required 只显示星号。Tern 0.9.9 实测中，Input 的 `required`／`aria-required`／`ariaRequired` 和 Editor 的 `required` 均未产生辅助技术的原生 required 状态，本版不声称支持该状态。字段输入使用对应可见标签作为辅助技术名称。保存、提交、测试或加载前复用既有 validators，按字段语义校验必填、条件必填和类型／范围。错误就地关联字段并聚焦首个错误，保留所有输入和弹窗，不只显示 toast，不发送请求、不暂存变更、不改变布局或标记 dirty。修改字段时清除或重新计算对应错误；后端错误仍显示实际原因。空白配置、路径和名称判为未填写，但保留输入原文，不对数据统一 trim。SQL 的省略／默认、SQL NULL 和合法空字符串分别处理；Redis key、field、member、value 的空字节及 `base64:` 空值是合法数据，不等于未填写配置。

## SQL、历史与格式化

- 新查询未执行时隐藏结果区域，编辑器填满可用空间。执行后显示状态、只读结果或错误，收起结果恢复编辑空间。编辑 SQL 或从历史打开文本会清除不相关旧结果。
- 查询提供执行全部、执行选区和当前语句。Command／Ctrl+Enter 执行选区或当前语句，追加 Shift 执行全文；无有效选区时禁用选区执行。
- SQL 主工具栏提供“执行计划”，优先使用非空选区，否则使用当前语句；只接受一条可安全识别的 MySQL 查询或 DML，发送普通 `EXPLAIN FORMAT=JSON`，不使用 `ANALYZE`。无有效目标时禁用并说明原因；该入口没有专用快捷键。
- 行号与高亮、文本滚动对齐。每条可识别语句首个 SQL token 所在行提供执行按钮，标明序号与行范围；同一行多语句先选择目标。引号、注释中的分号不拆句，存储程序、客户端指令、未闭合输入和不可靠边界显示原因。
- 选区右键菜单提供执行、普通 `EXPLAIN FORMAT=JSON`、格式化、复制、剪切和全选。执行计划仅接受单条可解释语句，不使用 `ANALYZE`。菜单保留所属标签的 UTF-16 选区，文本变化关闭旧菜单。
- 格式化只替换选区，保持外围文本、注释、Unicode 和撤销能力；无法可靠处理时保留原文并显示原因。浏览器稿通过 [jsDelivr 固定版本 CDN](https://cdn.jsdelivr.net/npm/sql-formatter@15.9.0/dist/sql-formatter.min.js) 引入 [sql-formatter 15.9.0](https://github.com/sql-formatter-org/sql-formatter)，使用 SRI 校验；库采用 [MIT License](https://cdn.jsdelivr.net/npm/sql-formatter@15.9.0/LICENSE)。加载需要网络，失败时其他原型交互仍可使用，格式化明确报错；仓库不分发该 JavaScript bundle。
- 原生选区格式化直接链接 Rust `sqlformat`，用当前 `sql_mode` 核对格式化前后 token，经一次编辑事务接入撤销，不启动 Node、JavaScript runtime 或 WebView。
- DDL 是带行号的只读高亮文本，可复制完整内容，不显示执行按钮。查询高亮使用原生 `lang=sql` 和 `nowrap`，文本、行号与 gutter 共用滚动容器。
- DDL 复制使用图标按钮，保留 tooltip、可访问名称和全文复制。
- 历史入口保留在侧栏；直连与 Archery 完全复用布局：顶部搜索条件及“查询”按钮，宽屏左侧列表、右侧全文预览，选中行有明确样式，底部提供打开操作；窄屏改为上下排列，弹窗头尾固定、正文滚动，所有控件和空态支持中英文。首次打开立即以空条件加载第一页；输入只修改条件草稿，不发请求或替换结果，点击“查询”或 Enter 才提交条件并回第一页，清空条件后查询全部。翻页及更改页大小沿用上次已提交条件，页大小变化回第一页；加载中和空结果禁用打开。直连历史默认不自动删除，可在设置中显式启用保留规则，按存储层分页并搜索保留的全部记录。Archery 按平台 offset／limit／search 和实际 total 分页。底部分页使用配置的历史页大小及共享候选，按已知信息显示页码和总数；换源立即读取该来源第一页。关闭弹窗保留原内容、结果及草稿；表标签打开历史 SQL 时使用独立查询标签，保留原表结果与编辑基线。

查询编辑器由应用维护 UTF-16 键盘选区；宿主协议的编辑事件不携带可用于执行的选区范围，因此不将鼠标拖选作为原生查询执行选区。其他表单和数据编辑使用 native editing。剪切收到宿主剪贴板成功回执后再次核对标签、全文和选区，拒绝、超时或上下文变化均保留文本。浏览器原型的鼠标选择能力不能视为 TSP 已支持。

grid 撤销支持 macOS Command+Z 和通用 Ctrl+Z。新建连接的类型卡片支持方向键循环选择、Home／End 定位和 Space／Enter 确认；保存期间、已有连接编辑态及 Archery 预览态均禁止切换，返回新建配置后恢复。Ctrl+Q 绑定应用退出；Command+Q／Command+W 由宿主处理。下拉方向导航、grid Delete／Backspace 删除、redo 尚无应用绑定。插件只有命令面板入口，没有额外快捷键。


## Redis 类型、编辑与 CLI

key 浏览区包含 pattern、类型筛选、刷新、已加载数量、列表／树切换和“加载更多”。每次沿当前 SCAN cursor 追加并去重，保留原始 key 身份、仍有效的选择与目录展开；不显示页码或上一页／下一页。树只组织已加载 key，不代表服务端目录、全库计数或一致性快照；原型的本地包含匹配不等于 Redis glob。加载中、可加载更多、扫描完成、失败和受限分别表达，空批次不代表结束，只有 cursor 为零且待消费数据耗尽才完成。刷新、过滤或 DB 变化结束旧扫描，迟到回包不得追加到新上下文；放弃的 cursor 显式释放，并按空闲期限回收，过期不能隐式重扫。

树按原始 key 字节中的 `:` 分成多级目录，每个目录初始折叠，点击只切换该级；展开状态按连接、Redis DB 和完整前缀隔离。父目录收起不清除子目录已展开状态，不改变当前 key、详情、CLI 或草稿；不再可见的选择失效。空分段保留；同名 key 与前缀目录是不同节点；二进制和字面 `base64:` key 维持可逆身份，不能按显示文本重建 key。树的叶节点只显示末级名称，空末级显示 `∅`，保留类型和 TTL；列表仍显示完整 key，完整路径保留在 tooltip、详情标题和复制操作中。

打开另一个 key 的独立标签时继承当前 pattern、类型筛选、树模式和目录展开状态，保留资源浏览上下文。

列表与树在同一滚动区浏览已加载节点；每次加载受批量、响应字节和客户端内存预算约束，达到界面保留预算时明确受限并停止追加，不能通过隐藏旧 key 或翻到另一“页”伪装为持续累积。深 key 使用扁平可见行和借用前缀，不为折叠的每一层复制完整前缀或创建界面节点。

key 名称单行等宽，右侧以紧凑双行显示 `STR / HASH / LIST / SET / ZSET` 和 TTL。永久显示 `∞`，有限期限可显示 `≈59m / ≈2h / ≈6d`；不存在与已过期不能使用永久标识。完整 key、类型和期限保留在 tooltip 与详情头部，不为角标预留大块固定空白。

列表和树叶使用相同的 key 多选：普通点击单选并打开，Shift 选择可见连续范围，Command／Ctrl 增选或取消且不抢当前内容；右击已选项保留选集，右击未选项先单选目标。选区以原始 key 字节身份限定连接和 DB，筛选、刷新、目录收起或 DB 切换时清除不再有效的选择。右键打开针对目标 key，复制名称和删除针对整个选集。复制 key 名称是 JSON 数组，每项为可逆 UTF-8 字符串或 `{"base64":"..."}` 对象；换行及字面 `base64:` 文本无歧义。树目录不属于选集。

复合类型通过行号独立选择当前页条目：普通点击单选、Shift 连选、Command／Ctrl 增选或取消，翻页清除条目选区；单元格点击及 Shift 矩形选择遵循共享 grid 规则。右击已选条目保留选集，右击未选条目先单选目标，行操作针对该精确条目集。条目复制使用 `{type, entries}` JSON，每个条目的各字段采用 DataValue 型 `{type, value}`：字节以 Base64 表达，整数和浮点值以字符串保留精度及 `inf`；大值须完整异步读取，任何失败均不复制部分选集。工具栏 trash 只删除选中条目，标题 trash 删除整个 key。Hash field、List 元素、Set／ZSet member 不称作 key。身份和 List 编辑基线来自原始数据，不能由显示文本重建；确认冻结上下文与选集，必要的大值完整读取和校验成功后才整批暂存。List 按基线索引降序删除，整批作为一个撤销组。

Redis 复合值和 Direct CLI 的表格结果沿用共享分页器，按实际结果模式和保留范围翻页；未知总数不猜页数。各条 CLI 记录保留自己的命令、数据库与结果上下文，翻页不重放命令，不能把另一条记录的分页状态带入当前结果。

多 key 删除确认冻结连接、DB、标签和完整原始目标；统一草稿栏展示待删除 key 数及预览、提交和丢弃操作。批量草稿经 `change.open` 的 `targets` 建立独立 WATCH，返回 token、targets 和 `delete_keys` 操作；预览和提交携带 token、操作及与返回值原样精确匹配的目标数组。预览沿用 ChangePreview，以单个步骤展示 MULTI、一次 DEL 和 EXEC；提交报告实际 DEL 数量，冲突整批拒绝，丢弃按 token 释放。工作区仅持久化目标与意图，不保存可用 token；恢复后需重新确认并重新建立 WATCH。原型只演示确认、草稿、预览和显式提交，不执行命令。

批量目标支持 Redis 的任意实际 key 类型，包括 stream 和模块类型；拒绝 database 及空类型目标。WATCH 后按 TYPE 核对所选类型，类型变化时报告冲突。

| 类型 | 内容与编辑 | 约束 |
|---|---|---|
| String | 文本／JSON／HEX；独立 Value 输入 | 格式切换不改写字节，JSON 不是 RedisJSON；无法解析时保留原值及说明 |
| Hash | Field／Value 两列，两个独立输入 | field 唯一，保留字节，不用换行拼接 |
| List | Index／Value 两列，只读 Index | 保留顺序和重复值，以有效编辑基线定位 |
| Set | Member 列及编辑输入 | 唯一且无序，浏览排列不是集合顺序 |
| ZSet | Member／Score 两列及独立输入 | member 唯一，score 单独校验且可重复，修改后顺序可能变化 |

TTL、重命名和删除使用独立对话框，保留完整对象上下文；TTL 区分保留、设置和移除期限。修改先进入所属 DB／key 的草稿，再预览与显式提交；真实编辑由 WATCH／编辑令牌保护，默认保留 TTL。

详情标题固定显示完整 key，依次提供重命名（edit）、复制 key（copy）、删除 key（trash）；重命名和删除仅在读写且基线有效时可用。TTL 编辑独立于内容工具栏并遵循写入与基线约束。String 内容区依次提供 Text／JSON／HEX、编辑、独立导入、独立导出、复制值；复合类型沿用原生 Fields／Items／Members 内容标题与共享 grid 序号列，并按类型具名提供编辑或新增／删除选中条目、列设置、独立导入、独立导出和复制值。标题和条目工具栏删除按钮使用 quiet 按钮背景、边框和 hover，仅 trash 图标为危险色；删除菜单项与确认按钮使用 danger 语义。写操作在只读或基线无效时禁用或按已有状态隐藏；可读、导出和复制仍可用，不能误禁用导出。无通用更多入口。复制完整值不包含草稿：String 使用原始 UTF-8，非 UTF-8 使用 Base64；复合类型以包含类型和完整成员的 JSON 表达。后台读取完整缓存和大字段，UI 分批发送，切换 key／tab 或修改草稿会使旧复制失效；宿主确认后才显示成功。
String 大值在 Text／JSON／HEX 旁提供“读取完整值”，异步分块读取后按所选格式展示真实完整内容；只读复合类型可选中单元格，通过底部“单元格详情”读取完整值，不建立编辑基线或草稿。
List、Set、ZSet、Hash 设置对话框的 Value／Member 使用多行文本域；Index、Field、Score 保持各自控件类型。所有字段竖向排列并各占满一行，包括 ZSet 的 Member 和 Score。

CLI 由标题与操作、连续执行记录、固定输入三层组成，显示当前连接和 DB。每次执行将当时的命令、实例／DB、状态、耗时和返回内容追加到记录末尾；多条命令的返回按执行顺序连续展示，后续执行或编辑输入保留旧记录及其归属。标量、空值、错误和表格在各自命令下展示；执行中条目结束时只更新该条目的状态与结果。输出区独立纵向滚动，执行后显示新记录，用户可向上查看此前内容；普通重绘保留阅读位置。记录在所属连接／标签会话内保留，切换 DB 不清空，切换标签或连接时恢复对应记录。历史入口用于查找既往执行并回填输入；Enter 与执行图标共用入口。直连 CLI 支持收起，Archery CLI 保持全高主面板，短视口下输入、停止与记录浏览可达；DB 和 CLI 收展状态在重开后恢复。

直连 Redis CLI 顶部提供原生 split 拖拽条，向上拖动扩大 CLI、向下拖动缩小。CLI 标题中的高度按钮可进入键盘调整，输入区 Tab／Shift+Tab 在输入与高度控制间切换；方向键每次调整 5 个百分点，Home／End 将比例偏好设置为 15%／85%，Enter／Escape 返回输入而不执行。默认比例为 35%，数据区至少保留 8 个宿主文本行；CLI 的最小空间随宽窄增加，以容纳头部、可滚动记录和输入，宿主约束实际空间时不覆盖比例偏好。头部的命令和名称取首行最多 32 个字符，tooltip 保留全文，完整命令仍在记录与复制内容中。比例在当前 UI 工作区会话内保留，收起重开及切换标签后恢复；窗口缩放按比例重算。Archery 来源的 Redis CLI 占满剩余工作区，短屏同样优先保证头部、滚动记录和输入可达。

## 结构设计、批量替换与高级值编辑

HTML 设计稿直接通过直连 MySQL 表页的“结构”tab 浏览结构，并在该 tab 内使用“编辑结构”进入编辑态；资源树右键菜单的“结构”同样定位目标表的结构分区。结构分区统一承载浏览、编辑和草稿 DDL 预览，不再提供额外的“设计结构”按钮或菜单项，也不打开独立设计弹窗。只读连接只能浏览，不能编辑或预览。原有 DDL 分区仍展示对应表的原始示例 DDL。顶部“结构设计 · DDL 预览”是预览工具，定位 commerce.orders 的结构分区，已有草稿不被覆盖。

结构浏览和编辑采用“对象标签 → 结构 → 字段／索引／外键／CHECK／表选项”三级导航。字段名称、类型、NULL、默认值及注释在原 grid 内直接编辑，扩展属性位于下方；索引的名称、类型及可见性在 grid 内编辑，下方维护多个有序索引项；外键的名称、引用表和更新／删除动作在 grid 内编辑，下方维护引用库及多组列映射；CHECK 直接在 grid 内编辑名称、表达式和启用状态；表选项使用紧凑属性 grid。结构草稿按表标签隔离，切换分区或表标签保留；关闭含未丢弃结构修改的标签前须先处理草稿。生成的 DDL 在原表结构分区冻结预览，继续编辑先解除冻结；新建表、视图和触发器保留独立工作台。HTML 提交始终禁用，生产提交继续使用 Engine 的冻结计划与最终确认。

批量替换将条件、冻结范围、计数、逐项前后值和执行结果分开显示。预览项支持排除与重新纳入，冻结后须先丢弃计划才能改变条件。SQL 与有序参数分区展示，不拼造插值 SQL；收集不完整、正在处理、计划失效或缺少提交条件时禁用相应动作，并保留原因。

高级值编辑沿用 Text／Hex／JSON／XML／图片分区。原生界面在存在未应用修改时保留当前输入并提示先应用，再允许切换模式；HTML 示例切换保留各模式输入和文件路径。当前窗口修改先“应用修改”到值会话，再“加入草稿”；未应用的窗口修改、请求处理中或只读状态不能加入草稿。两步均不代表提交数据库。文件路径与覆盖开关、导入导出及外部编辑操作独立分区；媒体预览和文件操作只在实际状态允许时启用。

遗留编辑文件在设置中使用平面列表与结构化详情，展示可识别的来源、状态、大小及引用信息，完整登记数据默认折叠。服务端的活动状态不等于本窗口持有文件：导出和清理须以本客户端实际领取的文件版本为准，Engine 仍重新核对权属、版本与引用。清理使用危险操作确认；领取仅授予本地文件管理能力，不恢复数据库编辑基线或提交权限。

HTML 的结构计划、替换预览和模式切换仅操作本页示例，始终说明不连接数据库、不执行 SQL、不访问文件；示例提交和真实文件操作保持禁用，不能制造成功结果。

## 详情与语言

底部详情按任务、错误、导入预览、资源、草稿及恢复来源显示明确标题。任务详情保持图标、操作标题、右侧状态 tag 和带分隔线的双列摘要：连接／数据库、完整资源、真实耗时、结果行／列或多结果数量及真实开始时间；结果表逐项显示序号、类型、行数和状态。执行文本、错误分别独立分区，任务 ID 等内部标识放入默认折叠且可复制的完整诊断；SQL 默认只显示一次，`statements` 等结构保留在完整诊断，不重复铺陈原始 JSON。其他详情按错误、字段变更、结果、映射等内容分区和表格展示，未知对象用字段树、数组用行展示。

空间不足的窄屏中，任务详情摘要由双列改为单列，正文独立滚动，标题与必要操作保持可达；宽屏使用双列摘要。

任务详情使用任务创建时冻结的连接、provider 和完整资源上下文，不能借用当前活动标签；查询数据库在实际开始时从物理连接读取，正确保留之前 USE 的结果，排队时不假设初始数据库。真实 `started_at` 与 `elapsed_ms` 记录在既有 summary 的任务元数据中，上下文存于既有 params；不能用 `created_at` 冒充开始时间。未开始任务显示未开始，历史缺失或无法恢复的时间、耗时与上下文显示“未记录”，进行中耗时按实际状态呈现。结果 kind、列数和完成状态来自实际结果缓存元数据，列未知或缓存已释放时显示“未记录”，不能写成 0；未知结果集不能计作已确认结果。

查询文本来自实际提交文本，浏览 SQL 模板与 Redis 命令来自真实执行路径，区分构造和已发送，参数化 SQL 不伪造插值；Redis 命令保留可逆字节身份及实际发送顺序。记录有界时显式标记截断，缺失时显示“未记录”，不能根据资源名拼造执行文本。内容按所属标签和任务隔离。

应用设置位于侧栏底部，支持跟随系统、简体中文和 English。可见文案、菜单、tooltip 和可访问名称统一翻译，SQL、对象名称、用户输入、数据与数据库原始错误保留原文。切换语言保留 SQL、选区、表单、搜索、数据库勾选和草稿。

应用设置分为“常规”“编辑与文件”“Archery”“MCP”四个下划线 tab，默认常规。常规承载语言、UI 分页、通用读取／超时／内存限制和历史保留；编辑与文件承载编辑限制、外部编辑器和遗留文件；Archery 独立承载服务器列表与管理入口；MCP 承载响应行数与并发限制、审批策略、通知及连接权限。切换保留未保存值、选择及错误，不自动提交。分组与保存状态遵循 [应用设置规范](ui-guidelines.md#9-应用设置)。

设置采用受视口约束、最大参考宽度 1040px 的原生宽版 dialog，保留宿主标题、关闭、遮罩及 footer。语言为独立紧凑行；宽屏将分页、超时、资源限制、历史等平面分组并排两列，760px 及以下改单列，正文独立滚动；编辑器长参数、遗留文件及连接权限占整行。字段使用 SDK Row Field，范围与单位说明位于标签附近，减少额外行高；独立布尔值使用 Switch，集合选择仍使用多选。切换保留未保存输入；常规 footer 只保留重新加载与 primary 保存，Archery 管理的服务器独立保存。关闭、Ctrl+Q 退出与重新加载共同执行 [草稿检查](ui-guidelines.md#46-草稿关闭与危险确认)。HTML 配置仅操作页面示例，状态模拟入口独立于常规 footer。

MySQL、Redis 及 Archery 的连接表单不提供 MCP 配置。已有审批策略由模型基线保留，新连接使用全局默认；在 MCP tab 选择具名连接后管理其策略和细粒度权限。连接策略可选关闭审批（`off`）、危险操作审批（`dangerous`）、所有写入审批（`all_writes`），改变策略不会扩大数据库授权。全局设置、连接权限与审批策略分别标明保存范围及未保存状态；生产连接策略在选择后单独即时保存，并在控件附近说明，存在未保存权限规则时先要求保存。权限草稿按连接保留，读取和保存受 revision／请求归属约束，失败保留输入与重试路径。Archery 服务器的保存属于服务器表单，不由全局保存按钮承接。

浏览器原型仅将语言偏好保存到本地存储，失败时当前会话仍应用选择并提示。原生偏好由 Core 按数据目录持久化，经 Engine 同步多窗口；系统语言来自 UI 进程所在系统。只判断首选语言，Hans、CN／SG 和裸 `zh` 使用简体中文，Hant、TW／HK／MO 及其他不支持语言使用英文；显式脚本优先于地区。

## MCP 待办

布局、尺寸、组件和状态要求见 [UI 设计规范第 8 节](ui-guidelines.md#8-mcp-待办设计)。状态栏入口打开原生对话框，以“待审批”“待认证”“Agent 任务”三个标签区分工作，不再以状态栏轻浮层承载完整工作流。

审批展示冻结目标、命令、绑定参数、状态与到期时间，完整诊断默认折叠。每条审批右侧使用拒绝（x）、批准（check）图标，tooltip 与可访问名称保留完整动作；先选择并加载请求，只有 Engine 返回可决定且仍 pending 时启用，加载或提交期间禁用。行选择与图标按钮并列，不嵌套按钮；footer 仅保留关闭。操作不能扩大权限或重复派发，关闭对话框不改变审批决定。认证分区只显示连接与控制窗口信息，进入既有密码／OTP 表单时关闭待办对话框；其他窗口只读观察，不回显秘密。任务分区保留真实状态、错误、结果选择和共享分页器，只对当前已返回并保留的数据分页，不推动 Agent 继续取数；过期结果不能恢复或重执行。

首次打开优先展示待审批，其次待认证；用户切换后后台刷新不抢标签。加载与空态互斥，错误就近显示，长连接名、命令和窄窗口中操作保持可达，列表选中态同时提供可访问状态与可见键盘焦点。HTML 另提供未选择、加载中、详情失败、审批已结束及结果过期示例；失败可重新选择预览请求，终态和不可用结果不允许重复提交或续读。批准、拒绝、认证和刷新仅展示“未发送”的预览说明，不作为真实业务成功证据。

## 验证与维护

修改设计时直接更新此说明和唯一交互稿。对照相同内容区尺寸和数据分别检查浏览器交互与原生界面；覆盖窄屏、空态、错误、选择、编辑、草稿、语言和 CDN 不可用路径。验证三个置顶连接入口、品牌角标、共用服务器表单、按钮顺序、非零批量预览、CA／TOTP 状态、多窗口共享认证及接手、删除占用保护、首次历史加载与全量分页、字段级必填和无连接／有连接快捷键帮助 overlay；浏览器示例不能充当真实服务或原生验收。原生数据库、剪贴板及平台支持的既有运行证据见[技术方案运行记录](technical-design-0.1.0.md#11-实现与运行记录)。

视觉对照时保留原生字体由宿主决定、浏览器使用回退，以及 overlay 阴影、模糊与控件由原生 SDK 绘制等差异。示例连接、标签数量及任务数值与真实运行数据分别表达，不能把示例值当作实际执行证据。
